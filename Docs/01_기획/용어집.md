# 용어집

기획 문서·UI·코드에서 같은 개념을 같은 이름으로 부르기 위한 표.
**코드 식별자** 열은 본 작업(`Assets/ARES/`) 코드에서 쓰는 영문 이름이다. 새 용어가 생기면 여기에 먼저 추가한다.

## 세계관 · 주체

| 용어 | 코드 식별자 | 설명 |
|---|---|---|
| 기관 | `Agency` | 플레이어가 소속된 안전관리기관. 구체 설정 미정 |
| 요원 / 플레이어 | `Player` | 기관 소속으로 이상 공간에 진입하는 사람 |
| 민간인 | `Civilian` | 이상 공간에 유입되어 갇힌 사람. 구조 대상 |
| 엔티티 | `Entity` | 이상 공간에 존재하는 존재. 성향에 따라 아래로 나뉨 |
| └ 적대 엔티티 | `EntityDisposition.Hostile` | 플레이어·민간인을 위협 |
| └ 중립 엔티티 | `EntityDisposition.Neutral` | 수칙을 지키면 피할 수 있음 |
| └ 우호 엔티티 | `EntityDisposition.Friendly` | 플레이어를 도울 수 있음 |
| 이상현상 | `Anomaly` | 공간에서 일어나는 설명 불가능한 현상. 수칙서가 다루는 대상 |

## 공간

| 용어 | 코드 식별자 | 설명 |
|---|---|---|
| 위험 지역 / 던전 / 이상 공간 | `Dungeon` | 같은 개념. 기획서는 섞어 쓰지만 코드는 `Dungeon`으로 통일 |
| 지형 | `DungeonLayout` | 최초 진입 시 무작위 생성, 이후 유지(영속) |
| 탈출구 | `Exit` | 민간인·플레이어가 던전을 빠져나가는 지점 |
| 안전지대 | `SafeZone` | 민간인이 위험을 피해 대기·집결하는 설치 시설 |
| 안전 경로 | `SafeRoute` | 비교적 안전한 이동 경로 |
| 유도표시 (이정표·유도 스티커) | `GuideMarker` | 민간인이 탈출구를 찾도록 돕는 설치물 |
| 시설 | `Facility` | 플레이어가 던전에 설치하는 것들의 통칭 (유도표시, 안전지대 등) |

## 정보

| 용어 | 코드 식별자 | 설명 |
|---|---|---|
| 수칙서 | `Rulebook` | 던전별 이상현상의 특성·대응법 기록. 던전마다 하나 |
| 수칙 | `Rule` | 수칙서의 항목 하나. 상태: 확인 / 미확인 / 오염 |
| 미확인 수칙 | `RuleState.Unknown` | 아직 알아내지 못한 수칙 |
| 정보 오염 | `RuleState.Corrupted` | 기존 수칙이 틀리게 바뀐 상태 (지역 관리 이벤트) |
| 단서 | `Clue` | 던전에서 조사해 얻는 힌트. 수칙 가설의 근거 |
| 가설 검증 | `RuleHypothesis` | 준비된 선택지 중 올바른 수칙을 골라 수칙서를 갱신하는 행위 |
| 생존자 정보 | `SurvivorIntel` | 구조한 민간인에게서 확률적으로 얻는 수칙·정보 |

## 진행 · 지표

| 용어 | 코드 식별자 | 설명 |
|---|---|---|
| Day (게임 내 날짜) | `Day` | 진행 단위. Day가 바뀌면 민간인이 생성됨 |
| 구조 | `Rescue` | 플레이어가 민간인을 탈출시키는 것 |
| 자력 탈출 | `SelfEscape` | 민간인이 플레이어 없이 스스로 탈출하는 것 |
| 생존률 | `SurvivalRate` | (구조 + 자력 탈출) / 해당 기간 생성 민간인 × 100. 던전별 |
| 재점검 | `Reinspection` | 생존률이 떨어진 던전에 재진입해 원인을 찾고 복구하는 것 |
| 범람 | `Overflow` | 관리 능력을 넘어선 이상현상이 던전 밖으로 넘치는 것 = 게임 오버 |
| 최후의 저항 | `LastStand` | 게임 오버 후 엔딩 미니게임 |

## 프로토타입 용어와의 차이

`Assets/Prototype`(namespace `DungeonProto`)은 Lethal Company식 감각 테스트용이라 이름이 다르다. 본 작업에서는 오른쪽을 쓴다.

| 프로토타입 | 본 작업 | 비고 |
|---|---|---|
| `EnemyAI`, `Enemy_Civilian` | `Entity` / `Civilian` | 프로토타입은 민간인 모델을 임시로 적에 씀 |
| `SpawnKind.Loot` | (해당 없음) | 기획서의 보상은 루팅이 아니라 **구조 성과** |
| `SpawnKind.Extraction` | `Exit` | |
| `SpawnKind.EnemySpawn` | `EntitySpawn` | |
