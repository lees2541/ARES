# 미정 사항

아직 팀이 정하지 않은 것들. 구현이 이 항목에 걸리면 **임의로 확정하지 말고** 묻거나, 설정 가능하게 만들고 "임시 가정"란에 적는다.
결정되면 [결정 기록](../05_결정/결정-기록.md)에 추가하고 이 표에서 상태를 `결정됨`으로 바꾼 뒤 결정 번호를 적는다.

## 기술

| # | 항목 | 상태 | 메모 |
|---|---|---|---|
| T-01 | 네트워크 솔루션 (Netcode for GameObjects / Mirror / FishNet / Photon 등) | 미정 | 정하기 전에는 네트워크 패키지를 추가하지 않는다 |
| T-02 | 타겟 플랫폼 (PC/Steam 등) | 미정 | 현재 URP 에셋에 PC·Mobile 둘 다 있음 (템플릿 기본값) |
| T-03 | 던전 영속화 방식 (시드 저장 + 변경분 저장 등) | 미정 | 프로토타입 생성기는 같은 seed → 같은 맵이라 시드 저장과 잘 맞음 |
| T-04 | 세이브 데이터 형식·위치 | 미정 | |
