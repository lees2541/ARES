## 문서 사용법

**보기·편집** — 평소 쓰는 IDE에서 `.md` 파일을 열면 된다. 링크는 클릭해서 이동할 수 있다.
- Visual Studio: `.md` 파일을 열면 편집기 위에 미리보기가 함께 보인다
- Rider: `.md` 파일을 열고 오른쪽 위의 미리보기 버튼
- VS Code: `Ctrl+Shift+V` (미리보기)
- GitHub 웹: 저장소의 `Docs/` 폴더에서 바로 읽을 수 있다
- Obsidian을 쓰고 싶으면 `Docs/` 폴더를 볼트로 열어도 된다 (개인 설정 `.obsidian/`은 git에 올라가지 않음)

**새 문서 만들기**
1. 맞는 번호 폴더를 고른다 (회의록 → `04_회의/`)
2. `99_템플릿/`의 템플릿 파일을 복사해서 이름을 바꾼다
3. 파일 이름은 띄어쓰기 대신 `-` (예: `2026-11-24-세번째-회의.md`)
4. `YYYY-MM-DD`, `제목` 같은 자리를 채운다
5. 이 홈 문서의 "지도"에 링크를 추가한다

**링크 쓰는 법** — 표준 마크다운 상대 링크를 쓴다.
- 같은 폴더: `[용어집](용어집.md)`
- 다른 폴더: `[용어집](../01_기획/용어집.md)`

**이미지** — `Docs/_attachments/`에 넣고 `![설명](../_attachments/파일.png)`처럼 링크한다. 큰 이미지는 너무 많이 넣지 않는다.
