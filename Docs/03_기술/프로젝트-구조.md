### 주의할 점
- `Civilian_Male_01` 모델이 `Assets/Prototype/Models/`와 `Assets/Resources/`에 **중복**으로 있다.
- `Assets/Resources/` 안의 모든 것은 빌드에 무조건 포함된다. 모델·텍스처는 `Resources.Load`가 필요하지 않다면 다른 폴더에 두는 게 좋다.
- `TutorialInfo/`는 정리 대상 후보 (담당자 확인 후).
- 깃허브 테스트용이던 `Scenes/a`, `Scenes/b`, `Prefabs/asdf.cs`는 2026-11-23에 삭제했다.

## 본 작업 권장 구조 (팀 합의 전 — [미정 사항](../01_기획/미정-사항.md) T-05)

프로토타입과 섞이지 않도록, 본 작업은 `Assets/ARES/` 한 곳에 모은다.

```
Assets/ARES/
├─ Scripts/
│  ├─ Runtime/
│  │  ├─ Core/          게임 루프, Day 진행, 세이브
│  │  ├─ Player/
│  │  ├─ Dungeon/       생성, 영속화
│  │  ├─ Entities/      엔티티 AI
│  │  ├─ Civilians/     민간인 AI, 구조
│  │  ├─ Rulebook/      수칙서, 단서, 생존자 정보
│  │  ├─ Facilities/    유도표시, 안전지대
│  │  ├─ Management/    생존률, 지역 이벤트
│  │  ├─ Network/       (네트워크 결정 후)
│  │  └─ UI/
│  └─ Editor/           에디터 전용 툴
├─ Data/                ScriptableObject 에셋 (던전 정의, 수칙, 엔티티 데이터)
├─ Prefabs/
├─ Scenes/
├─ Art/                 Models / Materials / Textures / Animations
├─ Audio/
└─ Settings/
```

- 스크립트 폴더마다 Assembly Definition(`.asmdef`)을 두는 것을 권장 (컴파일 시간 단축, 의존 방향 강제). 예: `ARES.Runtime`, `ARES.Editor`.
- namespace는 폴더를 따른다: `ARES.Dungeon`, `ARES.Rulebook` …

## Git 규칙 요약
- 브랜치: `main`(기본) / `dev`(본 작업용) / `prototype`(프로토타입용). 개인 작업 브랜치는 작업할 브랜치에서 갈라 만든다 (예: `proto/lees2541`). 병합 흐름은 미정 ([미정 사항](../01_기획/미정-사항.md) T-06)
- 개인 폴더: `Assets/Imports/*`, `Assets/Test/*` (폴더와 `.gitkeep`만 공유)
- 바이너리는 LFS. 새 바이너리 확장자를 쓰면 `.gitattributes` 확인
- 씬은 여러 명이 동시에 고치지 않는다. 작업 씬을 나누거나 프리팹 단위로 작업
- `.meta`는 항상 에셋과 함께 커밋
