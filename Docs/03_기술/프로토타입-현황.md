# 프로토타입 현황

`Assets/Prototype/` — 던전 맵과 1인칭 감각을 빠르게 확인하기 위한 그레이박스. namespace `DungeonProto`.
본 작업에서는 **참고만** 하고 의존하지 않는다 ([프로젝트 구조](프로젝트-구조.md)). 용어 차이는 [용어집](../01_기획/용어집.md) 마지막 표 참고.

## 씬
- `Assets/Prototype/Scenes/DungeonPrototype.unity`

## 런타임 스크립트 (`Scripts/`)

| 파일 | 줄 수 | 역할 |
|---|---|---|
| `DungeonGenerator.cs` | 883 | 시설형 던전 생성기. 외부 착륙지 + 복도·방이 무작위로 이어진 내부. **같은 seed → 같은 맵**. 방 종류: Entrance, Corridor, Storage, Office, Machine, Hall. 루프 확률, 막다른 복도 제거, 입구로부터 깊이(depth) 계산, 조명 고장 확률, 분위기 설정 포함 |
| `EnemyAI.cs` | 245 | NavMeshAgent 기반 적. 상태: Patrol → (소리) Investigate / (시야) Chase → (놓침) Search → Patrol, 접촉 시 Catch → Cooldown. 시야각·시야거리·소리 감지 거리(달리기/걷기) 설정 |
| `EnemyDirector.cs` | 100 | 플레이 시작 시 건물 내부만 NavMesh 런타임 베이크, EnemySpawn 마커에서 적 순차 스폰. `DungeonGenerator`와 같은 오브젝트에 붙음 |
| `PrototypePlayer.cs` | 195 | CharacterController 1인칭. 걷기/달리기(스태미나)/웅크리기/점프/손전등/물체 잡기. 소음 반경 제공(웅크리거나 멈추면 0). 잡히면 들고 있던 것을 놓고 착륙지로 복귀 |
| `SpawnMarker.cs` | 68 | 생성기가 배치하는 마커: PlayerSpawn, Loot, EnemySpawn, Extraction |

## 에디터 스크립트 (`Editor/`)

| 파일 | 역할 |
|---|---|
| `DungeonGeneratorEditor.cs` | 생성기 인스펙터: 생성 구역 수 표시, `Generate` / `New Seed` / `Clear` 버튼. 메뉴 **Tools > Dungeon Prototype > Setup Current Scene** — 현재 씬에 생성기·플레이어·달빛을 준비하고 맵 생성 |
| `EnemySetup.cs` | 메뉴 **Tools > Dungeon Prototype > Build Civilian Enemy** — Tripo로 만든 `Civilian_Male_01`을 적으로 쓰기 위한 자동 셋업: 임포트 설정(루프·Avatar) → Animator Controller → 적 프리팹 → 씬 EnemyDirector 연결 |

## 기타 에셋
- `Prefabs/Enemy_Civilian.prefab`, `Animation/Enemy_Civilian.controller`
- `Materials/Proto_*.mat` — 그레이박스용 단색 머티리얼 26종
- `Models/Civilian_Male_01/` — `Assets/Resources/`에도 같은 모델이 있음 (중복)

## 본 작업으로 가져갈 만한 것
- **시드 기반 생성** → 기획서 8.1 "지형 유지"와 바로 연결 가능 (시드만 저장하면 지형 재현)
- **소리·시야 감지 구조** → 엔티티 AI의 기본 감각으로 재사용 가능
- **NavMesh 런타임 베이크** → 민간인 AI 이동에도 필요
- **에디터 자동 셋업 패턴** → 모델 임포트 파이프라인

## 기획과 다른 점 (본 작업에서 바꿔야 할 것)
- 루팅(Loot) 중심 → 기획서는 **민간인 구조**가 보상의 근원
- 적대형 적만 존재 → 기획서는 적대/중립/우호 엔티티 + 수칙
- 매 플레이 새로 생성하는 구조 → 기획서는 **최초 생성 후 유지**, 설치물 누적
