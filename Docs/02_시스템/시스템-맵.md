# 시스템 맵

[게임 컨셉 기획서](../01_기획/게임-컨셉-기획서.md)의 기능을 구현 단위(시스템)로 나눈 표. **무엇이 이미 있는지 가장 먼저 확인하는 곳**이다.

- 이 표는 PM 쪽에서 브랜치를 합칠 때 갱신한다. 작업자는 이 표를 직접 고치지 않고 자기 시스템의 문서를 쓴다.
- 시스템마다 이 폴더에 [시스템 설계 템플릿](../99_템플릿/시스템-설계-템플릿.md)으로 문서를 만들고 여기서 링크한다.
- "현재 코드" 칸에는 다른 코드가 불러 쓰는 진입점(클래스 이름)을 적는다. 같은 역할의 코드를 새로 만들기 전에 이 칸을 확인한다.

**상태:** `없음` → `프로토타입` (그레이박스 검증용, `Assets/Prototype`) → `설계` → `구현 중` → `완료`
