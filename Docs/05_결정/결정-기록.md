# 결정 기록

팀이 확정한 사항과 이유. 한 번 정한 것을 다시 논의하지 않도록, 그리고 AI가 "왜 이렇게 되어 있는지" 알 수 있도록 남긴다.
뒤집을 때는 지우지 말고 새 항목을 추가하고 이전 항목에 `대체됨 → D-xxx`라고 표시한다.
큰 결정은 [결정 템플릿](../99_템플릿/결정-템플릿.md)으로 별도 문서를 만들고 여기서 링크한다.
