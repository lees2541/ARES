# 모델 올리는 곳

3D 모델 파일을 올리는 폴더입니다. **이 폴더만 쓰면 됩니다.** Unity는 열지 않아도 됩니다.

## 올리는 방법

1. 이 폴더 안에 모델 이름으로 새 폴더를 만듭니다. (예: `Civilian_Male_01`)
2. Tripo에서 받은 파일을 그 폴더에 그대로 넣습니다. 파일 이름은 바꾸지 않아도 됩니다.
3. 평소처럼 pull → 커밋 → push 합니다.

## 폴더 이름 짓기

- 영어, 숫자, 밑줄(`_`)만 씁니다. 띄어쓰기와 한글은 쓰지 않습니다.
- 무엇인지 알 수 있게 짓고 끝에 번호를 붙입니다. (예: `Civilian_Male_01`, `ARES_Player_01`)

## 모델을 고쳐서 다시 올릴 때

같은 폴더의 파일을 새 파일로 바꾸고 다시 커밋·push 합니다. 이전 버전은 Git에 남아 있으니 지워도 괜찮습니다.

## 주의할 점

- 커밋할 때는 **이 폴더 안의 파일만** 올립니다. 다른 폴더의 파일이 바뀐 것으로 보이면 그 파일은 빼고 올립니다.
- 올린 뒤에 따로 할 일은 없습니다. 게임에 넣는 작업은 이수형이 합니다.
- 잘 안 되면 이수형에게 물어봅니다.
